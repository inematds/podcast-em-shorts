In short

podcast-em-shorts is a free Python toolkit that turns a long recording (podcast, live stream, interview, or class) into short vertical videos. It reads the transcript, finds segments that make sense on their own, cuts them to 9:16 with the face enlarged and the screen below, adds word-by-word captions, and checks every frame. It is for people who record a lot and don't have time to edit. You need a computer with Python and ffmpeg; no account, key, or paid service required.

What it is

Three tedious tasks, handled automatically

Choosing a segment, building the vertical video, and checking that nothing looks wrong. The kit does all three and leaves the final decision to you.

🔎 Finds the best segments

Reads the speech and scores each 20–59 s segment: numbers, "you," a turning point, a question, a conclusion. Flags segments that start mid-sentence, depend on the screen, or say "subscribe."

✂️ Cuts to 9:16 with face and screen

Finds the webcam automatically. The enlarged face is on top without cutting off the head; the screen is below, following changes on screen. A title at the top and yellow captions highlight each spoken word.

✅ Checks everything; you approve

Checks every frame (captions over the face, cut-off head, black screen, frozen image, audio) and the text (complete sentences). A local page shows you everything so you can approve it or ask for it to be redone.

How it works

One command per step—or one for everything

Each step saves a file in the episode folder, so you can stop, review, and continue. The tudo shortcut runs the whole sequence.

novo→ transcrever→ candidatos→ escolher→ layout→ render→ checar→ revisão→ exportar

3 cutting modes

tela+camera (screen+camera, live stream with webcam in the corner): face on top, screen below. camera (camera, camera podcast): follows the face. tela (screen, no face): screen in the center. The kit chooses automatically.

All settings in one file

Colors, font, caption size, minimum and maximum duration, and number of shorts per episode are in marca/marca.json. Change them there to update everything.

Your feedback becomes a rule

Asked for it to be redone? Turn your feedback into a personal rule (starting at R200) with one command, so the same mistake doesn't happen again.

Requirements

Python, ffmpeg, and the kit

Works on Linux and Mac without a graphics card. Local transcription (faster-whisper) is optional: you can also provide a ready-made transcript in JSON.

Ubuntu / Debian

Python 3.10 or newer and ffmpeg.

sudo apt install python3-venv ffmpeg git

Mac

With Homebrew installed.

brew install python ffmpeg git

The kit

Download it and install the libraries in a separate environment.

git clone https://github.com/inematds/podcast-em-shorts
cd podcast-em-shorts
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt faster-whisper
User guide · step by step

From a long video to approved shorts

The commands below use .venv/bin/python (the environment created in the requirements section). Replace minha-live with your episode name (lowercase letters, numbers, and hyphens).

1

Check the installation

Shows ok or falta for each component. The first time, it downloads the face detector (YuNet, ~230 KB) and checks its integrity.

.venv/bin/python pes.py doutor
2

Add the episode

Copies the video to episodios/minha-live/raw/. The original is never deleted.

.venv/bin/python pes.py novo minha-live --video /caminho/da/live.mp4
3

Transcribe

With faster-whisper installed, it runs on your computer. Already have a transcript with per-word timestamps (Whisper format)? Import it with --de-json.

.venv/bin/python pes.py transcrever minha-live --modelo small --idioma pt
# or, with a ready-made transcript:
.venv/bin/python pes.py transcrever minha-live --de-json transcricao.json
4

Correct names Whisper got wrong

Before cutting, replace incorrect words so the captions are accurate.

.venv/bin/python pes.py corrigir minha-live --trocar "Iá=IA"
5

Review the candidates and choose

Lists segments with scores, signals, and alerts. Choose by code (c01, c03…) and give each one a short title. Found a better segment while reading the transcript? Use manual with the first and last word numbers.

.venv/bin/python pes.py candidatos minha-live --top 12
.venv/bin/python pes.py escolher minha-live c01,c03 --titulo "s1=O pedido que a IA acerta" --titulo "s2=Seja o maestro dos agentes"
# segment chosen manually (words 1239 to 1315):
.venv/bin/python pes.py escolher minha-live manual --ajustar s1=1239:1315 --titulo "s1=A IA te dá tudo. E a liberdade?"
6

Build the shorts

layout detects the webcam and screen; render creates clips/s1.mp4, s2.mp4… in 1080×1920.

.venv/bin/python pes.py layout minha-live
.venv/bin/python pes.py render minha-live --todos
7

Run the checks

Each one ends with OK or FALHOU: motivo. Failed? Choose another segment or adjust the cut—don't hide the failure.

.venv/bin/python pes.py checar-quadros episodios/minha-live/clips/s1.mp4 --legendas episodios/minha-live/clips/s1.legendas.json
.venv/bin/python pes.py checar-conteudo minha-live s1
8

Review and approve

Opens a page on your computer with each short, its checks, a notes field, and the Aprovar (approve) and Refazer (redo) buttons. Your decision is saved in revisao.json.

.venv/bin/python pes.py revisao minha-live   # open the address shown (http://127.0.0.1:…)
9

Set aside the approved shorts

Copies only the approved shorts to aprovados/, along with supporting text (title and speech) for you to post wherever you like. The kit doesn't post anything.

.venv/bin/python pes.py exportar minha-live
10

Turn your feedback into a rule

The short's latest note becomes one of your rules in regras/MINHAS-REGRAS.md (R200, R201…).

.venv/bin/python pes.py regra --da-nota minha-live s1
.venv/bin/python pes.py regra "Título com no máximo 5 palavras" --quem conteudo
⚡

Shortcut: everything at once

Transcribes (or imports), picks the best candidates without alerts, cuts, checks, and shows the review command. Never approves anything automatically.

.venv/bin/python pes.py tudo minha-live --modelo small --idioma pt
# or with a ready-made transcript:
.venv/bin/python pes.py tudo minha-live --de-json transcricao.json
🤖

With Claude Code or Codex

The kit includes a skill with the step order and guidance on when to stop. Copy the folder into your agent's skills directory and ask, "make shorts from my live stream." Without an agent, follow the steps above manually.

mkdir -p ~/.claude/skills && cp -r skill/podcast-em-shorts ~/.claude/skills/
# Codex: read skill/podcast-em-shorts/SKILL.md at the start of the conversation
Examples

Three shorts from a 57-minute live stream

The "IA Superinteligente" (Superintelligent AI) live stream, with screen sharing and a webcam in the corner. Transcript: 6,443 words. All three pass the frame and content checks. With the transcript ready, the tudo shortcut took 1 min 20 s from video to three checked shorts, with the machine otherwise idle.

What the checks caught

While building these examples, the checks rejected a segment that began with "Então," ("So,") and a case where a hand pointing toward the face was detected as a second face. We replaced the first segment; the second led to a detector fix, with a test.

What a human eye caught

Reviewing frame by frame, we found a second head cut off at the top when the head touched the edge of the webcam frame. This became a rule: the crop never leaves the webcam frame. That's why human review is still required.
